# DnD Spell Search

This is just a small passion project I made for a group of friends. The idea is simple: You want to do something magical, but are not sure what rules apply. This app will help you find the relevant spell, because oh my god, are there too many of them. Access the app [here](https://swlbj4-gabriel-p0.shinyapps.io/dnd_spell_search1/).
